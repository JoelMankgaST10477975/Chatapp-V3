## Project Description
This is a Java-based console application for "QuickChat". It includes user registration, login authentication, and a messaging system. Users can send, store, and disregard messages. The application uses parallel arrays to track messages, generates unique IDs and hashes, and saves stored messages to a JSON file.

## Features Implemented
* **Part 1:** User registration and login with regex validation.
* **Part 2:** Message creation, validation (250 char limit), hash generation, and send/store/discard functionality.
* **Part 3:** Stored messages menu (search by ID, search by recipient, longest message, delete by hash, display report) and JSON file reading/writing.

## How to Run
1. Clone the repository.
2. Open the project in Apache NetBeans (or your preferred IDE).
3. Run the `ChatApp.java` file.
